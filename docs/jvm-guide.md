# Проверки JVM и сборщиков мусора

Сборка рассчитана на Java 21. Подготовлены прогоны одного WaterMc JAR на Temurin 21 G1, Temurin 25 G1, Oracle GraalVM 25 G1, GraalVM 25 ZGC и адаптированном наборе MeowIce G1. Для сравнения скорости нужны одинаковые куча, настройки, миры и нагрузка, прогрев и повторения с чередованием порядка. Время запуска и короткий тест на другом CPU не определяют лучшую JVM для рабочего сервера.

GraalVM запускает этот сервер как обычное Java-приложение через JVM и Graal JIT. Native Image — другой режим, здесь он не используется. [Документация Oracle GraalVM](https://docs.oracle.com/en/graalvm/jdk/25/docs/getting-started/).

`benchmarks/jvm/verify-native-jvms.py` сохраняет точные версии Java и проверяет запуск полного набора флагов. Успешный `-version` подтверждает только возможность старта. Параметры Graal-компилятора также требуют прогретой серверной нагрузки: произвольное свойство `-D` может приниматься без реального эффекта.

## Адаптация MeowIce

[Исходный проект](https://github.com/MeowIce/meowice-flags) ориентирован на Java 25+, GraalVM и Linux. Оригинальные наборы сохранены в `meowice-*.flags`. Локальный `meowice-g1-windows-fx4100.flags` исключает:

- `UseTransparentHugePages`, не поддерживаемый этой Windows JVM.
- `UseLargePages` и переопределение размера страниц: нужной привилегии Windows нет.
- Явные `UseFMA` и `UseFastStosb`: у локального CPU нет нужных возможностей.

Проверяется вся комбинация. Например, `MaxNodeLimit=240000` требует `NodeLimitFudgeFactor=8000`. Ранние пофлаговые результаты сохранены в `*.tsv`. Эта адаптация предназначена для локальной машины и не является рекомендацией для Ryzen.

Первый общий запуск с кучей 256 МБ завершился ошибкой: при регионе 16 МБ остаётся слишком мало регионов для `SurvivorRatio=32`. Он сохранён в `jvm-startup-256m.json`. Повторный запуск всех пяти наборов с 1 ГБ прошёл успешно: `jvm-startup.json`. В сценариях сравнения скорости предусмотрено 4 ГБ, в фоновых функциональных проверках — 2 ГБ.

Функциональные серверные сценарии завершились на всех пяти вариантах JVM. Подробности и ограничения доставки клиентам указаны в `local-verification.md`. В режиме `functional_only` тестовый стенд убирает флаги повышения приоритета Java из MeowIce и записывает это в метаданные. Полный адаптированный набор отдельно прошёл проверку запуска. Преимущество в производительности не установлено.

Для 7950X3D, 192 ГБ и 100 игроков окончательные флаги, размер кучи и сборщик следует выбирать по замерам с реальными плагинами. Выделять всю физическую память куче Java оснований нет.

Тестовые JVM явно задают `-Dstdout.encoding=UTF-8 -Dstderr.encoding=UTF-8`, чтобы русские ошибки в Windows-логах сохранялись без искажения. Эти свойства описаны в [документации JDK 21](https://docs.oracle.com/en/java/javase/21/intl/supported-encodings.html). Производственный Java-код этим не меняется.
