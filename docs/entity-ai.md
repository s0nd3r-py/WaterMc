# Entity-AI: активация и завершение поиска пути

## DAB

Унаследованный DAB уже ограничивал Brain.tick через activatedPriority, но использовал расстояние и не ограничивал обычные GoalSelector. Добавлен visibility-aware режим: у моба лениво создаётся состояние только при включённом DAB. Проверка видимости выполняется владельцем мира по отслеживаемому чанку игрока и серверному hasLineOfSight (предел проверки 128 блоков). Это серверная оценка видимости, а не пиксельная видимость или FOV клиентской камеры.

Пока моб не виден, интервал удваивается каждые unseen-backoff-step-ticks (по умолчанию 20): 1, 2, 4, 8, 16, затем заданный max-tick-freq (по умолчанию 20). Видимый моб возвращается к 1; ближние игроки, текущая цель боя, получение урона и езда возвращают 1 сразу, не ожидая следующей проверки видимости. visibility-check-interval по умолчанию 5, ограничен 1–20. Учитываются blacklist и исключение неводных мобов в воде. visibility-aware=false сохраняет расчёт интервала по расстоянию. Сам DAB остаётся выключенным по умолчанию.

Существующие guards Brain.tick применяют интервал к сенсорам и поведению. Новая интеграция Mob.serverAiStep ограничивает полные проверки goal/target selectors; requiresUpdateEveryTick goals, навигация, движение, прыжки и look control продолжаются. При выключенном DAB приоритет сбрасывается на 1. Убраны опасные нулевые интервалы и переполнение квадрата расстояния в конфигурации. LongJumpToRandomPos использует примитивный IntArrayList и ThreadLocalRandom вместо списка Integer и Collections.shuffle; распределение перестановок сохраняется, конкретный случайный порядок не заявляется побитово тождественным.

## Async Pathfinding

A* уже присутствовал в Leaf и выполнялся платформенным worker pool с отдельными evaluators и thread-local heap/neighbours. Теперь processingComplete отделён от nullable результата: пустой результат и исключение становятся терминальными, не вызывают повторный поиск и не оставляют callbacks в вечном ожидании. Владелец применяет результат при опросе; failure callbacks получают null. Цели копируются в неизменяемые BlockPos. Shutdown rejection явно отклоняется; PathFinder возвращает evaluator и результат null при отклонённой постановке.

Унаследованный режим A* остаётся opt-in и выключен по умолчанию. Он всё ещё содержит чтения живого Mob/PathNavigationRegion и вызов onPathfindingDone из worker. Полный неизменяемый снимок мира/моба и доказанная безопасность для Owned Regions не реализованы этим исправлением и не заявляются. Новый код не включает этот режим автоматически.

## Проверки

BrainActivationTest проверяет последовательность интервалов, немедленное восстановление, переполнение tick counter и крайние параметры. GoalActivationTest вызывает реальный Mob.serverAiStep с обычной и every-tick goal, проверяет снижение частоты и возвращение обычного темпа при отключении DAB. AsyncPathTest проверяет отдельный platform worker, owner callbacks, отсутствие повторных вычислений, null/exception terminal result, изменяемые исходные позиции и реальную production rejection policy. Живой серверный A/B по MSPT и проверки всех mob-механик при включённом DAB ими не заменяются.
