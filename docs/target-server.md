# Целевой сервер

Пользователь указал 8 ноября 2026 года:

- AMD Ryzen 9 7950X3D.
- 192 ГБ оперативной памяти.
- Около 100 игроков одновременно.
- Собственные закрытые плагины, которых нет на этом компьютере.

Локальная машина: AMD FX-4100, 16 ГБ, Windows. Здесь можно проверять сборку, корректность, совместимость с процессором и доставку пакетов. Эти проверки не определяют вместимость будущего сервера.

Пользователь продолжает играть в Minecraft. Наши сборки и функциональные проверки выполняются с пониженным приоритетом. Такие прогоны помечены `functional_only`; их значения TPS/MSPT, CPU и GC нельзя использовать как доказательство ускорения. Сравнение скорости в контролируемых условиях отложено.

Финальная приёмка требует реальных плагинов, мира, диска, ОС и настроек дальности прорисовки/симуляции. В каждой паре A/B нужны одинаковые Java, куча, снимок мира, seed и действия игроков. После прогрева — минимум три повтора с чередованием порядка. Нужны разнесённые игроки, тесный спавн, параллельная генерация чанков, сохранения, редстоун-фермы и TNT. Следует проверить задержки тиков и рост памяти за длительное время.

192 ГБ физической памяти не означают кучу Java на 192 ГБ. Её размер определяется живыми данными и плагинами; память также нужна ОС, файловому кэшу, нативным буферам и другим процессам. Выбор между G1 и ZGC требует сравнения на целевом сервере.

Совместимость с закрытыми плагинами остаётся открытой задачей приёмки. Публичный тестовый плагин и побайтовая проверка API не заменяют запуск реальных плагинов.
