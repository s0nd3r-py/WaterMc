WaterMc

Быстрое серверное ядро на базе Leaf для Minecraft 1.21.11. Быстрее генерация мира, быстрее запуск, плагины Paper работают без правок. A fast Leaf-based server core for Minecraft 1.21.11. Faster world generation, faster startup, Paper plugins work unchanged.

ВозможностиFeatures

Всё, что даёт Leaf, и сверху ещё большеEverything Leaf gives you, and more on top

WaterMc основан на Leaf (Paper → Purpur → Gale → Leaf) и переписывает горячие места сервера: генерацию мира, запуск, ИИ мобов и хранение данных. WaterMc builds on Leaf (Paper → Purpur → Gale → Leaf) and rewrites the server's hot spots: world generation, startup, mob AI and data storage.

🗺️

Быстрая генерация мираFast world generation

Больше потоков генерации чанков, плоский поиск биома и быстрый выбор точки спавна на новом мире.More chunk worker threads, flat biome search and fast spawn point selection on new worlds.

⚡

Быстрый запускFast startup

Свой загрузчик, ленивый DataFixerUpper и маппинги, которые грузятся только когда они нужны плагину.Own launcher, lazy DataFixerUpper and mappings that load only when a plugin needs them.

Толпы и фермыCrowds and farms

Дешёвое толкание мобов, кэш памяти мозга и поиск блоков из Lithium, лимит размножения.Cheap mob pushing, Lithium brain-memory cache and block searches, breeding cap.

Встроенный ViaVersionBuilt-in ViaVersion

ViaVersion и ViaBackwards внутри ядра одной настройкой. Свой экземпляр в plugins/ всегда главнее.ViaVersion and ViaBackwards inside the core behind one switch. Your own copy in plugins/ always wins.

Скрытие за стенамиEntity culling

Сервер не отправляет сущности, которых игрок точно не видит. Меньше трафика, ESP-читы слепнут.The server skips entities a player provably cannot see. Less traffic, ESP cheats go blind.

🚀 Запуск и плагины🚀 Startup and plugins

  • Свой загрузчикOwn launcherПомнит хэши библиотек в libraries/.watermc-launcher и не пересчитывает их на каждом старте.Remembers library hashes in libraries/.watermc-launcher and does not re-hash them on every start.
  • Кэш ремаппераRemapper cacheplugins/.water-remapped: хэши jar в hashes.tsv, плагины только на API не переотображаются.plugins/.water-remapped: jar hashes in hashes.tsv, API-only plugins are not remapped.
  • Ленивый DFU и маппингиLazy DFU and mappingsСхемы конвертации и таблицы Spigot↔Mojang строятся только по необходимости.Conversion schemas and Spigot↔Mojang tables are built only when needed.
  • Без GUINo GUIОкно консоли на Swing/AWT удалено вместе со всем деревом классов.The Swing/AWT console window and its class tree are gone.

🔧 Переписанные классы🔧 Rewritten classes

  • Climate.RTreeГраницы узлов в плоском long[14], результат совпадает с ванилью до бита.Node bounds in a flat long[14], results match vanilla bit for bit.
  • ChunkEntitySlicesПлоская копия габаритов, поиск соседей не трогает объекты сущностей.Flat bounding-box copy, neighbour searches skip entity objects.
  • LevelTicksПомнит ближайший срок и не обходит контейнеры до него.Remembers the nearest due time and skips scans until then.

НастройкиConfig

Всё новое включается в одном файлеEverything new lives in one file

Новые функции по умолчанию выключены, ядро стартует безопасно «из коробки». Пример из config/watermc.yml:New features are off by default, so the core starts safely out of the box. Example from config/watermc.yml:

network:
  multi-version:          # built-in ViaVersion + ViaBackwards
    enabled: true
    min-version: '1.21.5'
  raytrace-entity-culling:
    enabled: true
performance:
  stronghold-early-reject:
    enabled: true            # on by default
  dynamic-distance:
    enabled: true
    target-mspt: 40.0
gameplay-mechanisms:
  breeding-cap:
    enabled: true
    limit: 32
